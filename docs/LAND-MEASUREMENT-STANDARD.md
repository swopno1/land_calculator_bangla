# Land Measurement Standard for Bangladesh (বাংলাদেশের জমির পরিমাপ ও রূপান্তর মানদণ্ড)

**Application:** জমির হিসাব (Land Calculator BD)  
**Developer:** ViveScript Solutions (https://www.vivescriptsolutions.com/)  
**Base Canonical Unit:** বর্গফুট (Square Feet)  
**Standard Classification:** সরকারি প্রমিত মান (Official Bangladesh Survey Standard)

---

## ১. ভিত্তি একক ও রূপান্তর সূচক (Conversion Factors Anchored to Sq Ft)

অ্যাপের সমস্ত রূপান্তর একটি একক সেন্ট্রালাইজড রূপান্তর ইঞ্জিনের (`LandConversionEngine`) মাধ্যমে এবং ভিত্তিমূল হিসেবে **বর্গফুট (Square Feet)** ব্যবহার করে সম্পাদিত হয়:

| একক (Unit Name) | বাংলা নাম | প্রতীক (Symbol) | বর্গফুট মান (Square Feet Factor) | সম্পর্ক ও প্রচলিত হিসাব |
| :--- | :--- | :--- | :--- | :--- |
| **Square Feet** | বর্গফুট | ব.ফুট / sq ft | **১.০০** | ভিত্তিমূল (Base Unit) |
| **Decimal / Shotok** | শতাংশ / শতক | শতাংশ / dec | **৪৩৫.৬০** | ১ শতাংশ = ৪৩৫.৬০ বর্গফুট = ৪৮.৪০ বর্গগজ = ৪০.৪৭ বর্গমিটার |
| **Katha** | কাঠা | কাঠা / katha | **৭২০.০০** | ১ কাঠা = ৭২০ বর্গফুট = ৮০ বর্গগজ = ১৬ ছটাক ≈ ১.৬৫২৮৯ শতাংশ |
| **Bigha (Standard)** | বিঘা (প্রমিত) | বিঘা / bigha | **১৪,৪০০.০০** | ১ বিঘা = ২০ কাঠা = ১৪,৪০০ বর্গফুট = ১৬০০ বর্গগজ ≈ ৩৩.০৬ শতাংশ (৩৩ শতক) |
| **Acre** | একর | একর / acre | **৪৩,৫৬০.০০** | ১ একর = ১০০ শতাংশ = ৩.০২৫ বিঘা = ৬০.৫ কাঠা = ৪৩,৫৬০ বর্গফুট |
| **Square Meter** | বর্গমিটার | ব.মিটার / sq m | **১০.৭৬৩৯১০৪** | ১ বর্গমিটার = ১০.৭৬৪ বর্গফুট = ১.১৯৬ বর্গগজ |
| **Square Yard** | বর্গগজ (গজ²) | ব.গজ / sq yd | **৯.০০** | ১ বর্গগজ = ৩ ফুট × ৩ ফুট = ৯ বর্গফুট |
| **Hectare** | হেক্টর | হেক্টর / ha | **১০৭,৬৩৯.১০৪** | ১ হেক্টর = ১০,০০০ বর্গমিটার = ২.৪৭১ একর = ২৪৭.১০ শতাংশ |
| **Chattak** | ছটাক | ছটাক / chattak | **৪৫.০০** | ১ ছটাক = ৪৫ বর্গফুট = ১/১৬ কাঠা = ৫ বর্গগজ |
| **Ganda** | গণ্ডা | গণ্ডা / ganda | **২.২৫** | ১ গণ্ডা = ২.২৫ বর্গফুট = ১/২০ ছটাক = ৪ কড়া |

## ২. ঐতিহ্যবাহী ক্ষুদ্র এককসমূহ (Traditional Sub-Units)

দলিল ও খতিয়ানের আনা, গণ্ডা, কড়া, ক্রান্তির পরিমাপের ক্ষেত্রে:
- **১৬ আনা** = সম্পূর্ণ অংশ (১০০%)
- **১ কাঠা** = ১৬ ছটাক = ৭২০ বর্গফুট
- **১ ছটাক** = ২০ গণ্ডা = ৪৫ বর্গফুট
- **১ গণ্ডা** = ৪ কড়া = ২.২৫ বর্গফুট
- **১ কড়া** = ৩ ক্রান্তি = ০.৭৫ বর্গফুট (১০৮ বর্গইঞ্চি)
- **১ ক্রান্তি** = ২০ তিল = ০.২৫ বর্গফুট (৩৬ বর্গইঞ্চি)
- **১ তিল** = ০.০১২৫ বর্গফুট (১.৮ বর্গইঞ্চি)

## ৩. অঞ্চলভেদে প্রচলিত তারতম্য (Regional Variations in Bangladesh)

বাংলাদেশে সিএস (CS), এসএ (SA), আরএস (RS), এবং বিএস/সিটি (BS/City) জরিপের ক্ষেত্রে সরকারি প্রমিত পরিমাপ মান অনুসরণ করা হলেও কিছু প্রাচীন আঞ্চলিক প্রথা রয়েছে:

1. **প্রমিত সরকারি বিঘা (Standard Government Bigha):**
   - ১ বিঘা = ৩৩.০৬ শতক (৩৩ শতক হিসেবে সুপরিচিত) = ১৪,৪০০ বর্গফুট = ২০ কাঠা।
   - ঢাকা, খুলনা, ময়মনসিংহ ও দেশের অধিকাংশ প্রশাসনিক এলাকায় এটি ব্যবহৃত হয়।

2. **আঞ্চলিক বিঘা (Regional Bigha):**
   - রাজশাহী ও বরেন্দ্র অঞ্চলের কিছু অংশে **৪০ শতকে বিঘা**, কোনো কোনো এলাকায় **৫০ শতক** বা **৬০ শতকের বিঘাও** পূর্বে প্রচলিত ছিল।

3. **সিলেট অঞ্চলের 'কিয়ার' (Kiyar):**
   - সাধারণত ১২ থেকে ৩০ শতকে এক কিয়ার প্রচলিত।

4. **চট্টগ্রাম ও নোয়াখালী অঞ্চলের 'কানি' (Kani):**
   - সাধারণ কানি = ৪০ শতক (১৬ গণ্ডা = ১ কানি)।
   - শাহী কানি বা দ্রোণ = ১২০ শতক বা ১৬০ শতক পর্যন্ত হতে পারে।

> **গুরুত্বপূর্ণ নীতি:**  
> এই অ্যাপে বিভ্রান্তি এড়াতে বাংলাদেশ সরকারের ভূমি মন্ত্রণালয় ও জরিপ অধিদপ্তর কর্তৃক সর্বাধিক প্রামাণ্য ও আইনগত মানদণ্ড (১ বিঘা = ১৪,৪০০ বর্গফুট = ২০ কাঠা ≈ ৩৩.০৬ শতাংশ) ডিফল্ট হিসেবে রাখা হয়েছে এবং ব্যবহারকারীকে স্পষ্ট নোটিশ প্রদর্শিত হয়েছে।

## ৪. আইনগত দায়মুক্তি (Legal Disclaimer)

এই অ্যাপ্লিকেশনটি সাধারণ হিসাব, দ্রুত রূপান্তর ও শিক্ষা/সচেতনতামূলক উদ্দেশ্যে নির্মিত। জমি ক্রয়-বিক্রয়, রেজিস্ট্রি, নামজারি (মিউটেশন), সীমানা নির্ধারণ বা যেকোনো আইনি কার্যক্রমে ব্যবহারের পূর্বে সংশ্লিষ্ট রেজিস্ট্রি দলিলের চৌহদ্দি, মৌজা নকশা এবং পেশাদার সার্ভেয়ার (আমিন) বা সহকারী কমিশনার (ভূমি) অফিসের প্রত্যয়ন গ্রহণ বাধ্যতামূলক।
